# Changelog

## 1.0.0 (Unreleased)

Initial release.

- Canvas time series panel whose time axis glides continuously between data refreshes.
- Field options named like the built-in time series panel, so the panel type can be switched in
  both directions without losing settings.
- Lines with fill and opacity gradient, stacking, negative Y, thresholds, table legend, multi
  series tooltip, shared crosshair and tooltip, drag to zoom.
- Local test stack (Grafana OSS 13.3.1 and VictoriaMetrics) and production test dashboards.
